# Desmos Graphing Library for Typst

## Description
This library provides a simple and efficient way to add desmos graphs to your typst documents.

## Methods
- Pass data through typwire
    - https://typst.app/universe/package/typwire/
- Render data in desmos with (with headless chrome)
    - https://docs.rs/headless_chrome/latest/headless_chrome/
    - https://github.com/typst/typst/discussions/3479
- Screenshot using desmos api
    - Save image locally, then use image
    - On the page, have a link to the interactive desmos page
